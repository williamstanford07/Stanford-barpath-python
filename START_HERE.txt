STANFORD BARPATH

Update your existing app:
1. Right-click BarPath_Final.zip and choose Extract All.
2. Open the extracted folder.
3. In your GitHub repository, choose Add file > Upload files.
4. To change from the previous final version, upload these THREE files:
   phone.html
   cloud.py
   rendering.py
   If updating from an older version, also upload mobile.py, tracking.py,
   and session.py to keep the latest tracking fixes.
5. Commit the changes. Wait for Render to finish deploying the new commit.
6. Reload the app. The sample video should be gone.

Upload the extracted files, not the ZIP or the containing folder.
The other files are included so this is also a complete source package.
Your existing password and Render settings do not need to change.
Previously uploaded ZIP files named BarPath or Bar Path are not app code.
