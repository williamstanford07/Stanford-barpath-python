STANFORD BarPath Recovery 2 update

1. Extract this ZIP.
2. On your existing GitHub Stanford-barpath-python repository, use Add file > Upload files.
3. Upload the six .py/.html files at the repository root, replacing the same filenames. Commit changes.
4. Render may deploy automatically. Otherwise use Manual Deploy > Deploy latest commit.
5. Refresh the app. The heading should say PYTHON · RECOVERY 2.

Changes: default bar search radius 300 px (was 140), adjustable to 960 px (was 320), expands after lost frames up to full-frame search. Accepted nearby matches are retained. The selected clip continues through tracking losses and attempts recovery. Missing points stay blank; stale markers are hidden. Incomplete tracking no longer generates partial-rep or drift feedback.

Verification: nine tests passed. The supplied 399-frame, 13.3-second clip exported all 399 frames. Starting on the bar end at frame 0, 175 subsequent frames tracked and 223 had gaps. This confirms complete clip processing, not reliable tracking throughout the video. Larger search areas can match the wrong object; review the trace. Assisted hip/knee depth tracking is unchanged.
